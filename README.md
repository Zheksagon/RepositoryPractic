# Веб-приложение для проката и бронирования туристических товаров

### Веб-приложение, которое позволяет:
* Клиентам - выбирать товары из каталога и бронировать его на выбранные даты;
* Менеджерам (пока не реализовано) - подтверждать бронирования, оформлять выдачи и возвраты с отметкой о состоянии оборудования, рассчитывать штрафы за просрочку или повреждения;
* Администраторам (пока не реализовано) - управлять: каталогом, тарифами и категориями, сотрудниками и пользователями, складом и списанием оборудования, а также просматривать статистику и аналитику. 

## Стек, который использовался для разработки
* **Backend:** C# (ASP.NET Core)
* **Frontend** HTML, CSS, JS
* **База данных** SQLite
* **Инструменты** Git, Paint, VS Code, Visual Studio

## Роли и функционал 
1. **Клиент (100%) - регистрация/авторизация, просмотр каталога и переход на подробное описание товара с возможностью его бронирования, отображение брони в личном кабинете и отмены брони там же. Есть возможность просмотра истории бронирований отдельно для каждого клиента.**
2. **Менеджер (5%) - пока реализована регистрация/авторизация**
3. **Администратор (5%) - пока реализована регистрация/авторизация**

## Инструкция по запуску

### Требования
* Установленный [.NET SDK] (версии 8.0 или выше)
* Visual Studio (2022 и выше) или Visual Studio Code (с расширением C# Dev Kit)

### Шаги для запуска
1. Загрузите проект из этого репозитория. Нажмите **зелёную кнопку <> Code** и нажмите **Open With Visual Studio**.
2. Откроется окно в Visual Studio. Укажите в нём путь до папки, где вы хотите сохранить проект.
3. Теперь откройте терминал в Visual Studio. В верхней панели найдите вкладку **Вид** и найдите там кнопку **Терминал** (либо комбинацией Ctrl + ё).
4. Для применения готовых миграций и создания БД введите в терминале команду **dotnet ef database update**.
5. Чтобы запустить проект введите в терминал **dotnet run**. Проект автоматически запустится в основном браузере.
